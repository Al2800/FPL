## Context

The lab’s scarce asset is sealed, point-in-time rewards and fail-closed rubrics
for the evidence/challenger overlay — not raw GPU. Ticket 11 schedules the
subscription sol path; ADR-0024 declined a metered API arm. Platforms that turn
**dataset + harness + rubric** into eval → synthetic data → optional LoRA
training (e.g. Prime Intellect Lab / open Verifiers environments) may be a fit
for owning a graded improvement loop on the AI overlay, analogous to narrow
subagent post-training elsewhere.

This ticket is a **review**, not an implementation mandate.

## Scope

- Inventory existing sealed rewards: agent-eval golden cases, evidence/challenger
  schemas, policy gates, fork fixtures, GDR degrade contracts.
- Sketch one candidate environment (dataset + harness + rubric) from those
  artefacts; reward must stay proposal-only (legality, citations, unopposed
  adjustments, sealed outcome deltas where allowed).
- Compare options: local Verifiers-only eval loop vs hosted training/inference
  (Prime Intellect or other); cost, secrets, reproducibility, ADR impact.
- Recommend go / no-go / defer, and the smallest experiment if go.

## Done when

- A written review under `docs/` (or this ticket’s Answer) states: fit to the
  lab architecture, phase risks, ADR requirements, and a single recommended
  next experiment or an explicit deferral.
- No live `run_gameweek` path changes; deterministic core untouched.

## Boundaries
