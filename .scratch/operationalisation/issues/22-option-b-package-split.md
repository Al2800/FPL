## Context

ADR-0026 Option A (accepted route for ticket 12) fixed discoverability without
moving packages. The 6 August 2026 import-graph audit showed the split is
already true in the dependency graph: **no live module imports a replay
module**; dependencies flow one way (replay → live). Option B formalises that
boundary so live advisory code can never silently grow a replay dependency,
and so future eval/RL environment work (ticket 21) lands in the experiments
package rather than beside the deadline path.
