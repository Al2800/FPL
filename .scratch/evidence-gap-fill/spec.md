# Spec: fill 2026/27 evidence-family gaps for competitive advisory use

## Goal

Close the coverage gaps that keep the live initial-squad / forecast path on an
operational `ep_next` baseline, so the lab can compete on research-grade,
point-in-time evidence rather than a thin official-EP rehearsal.

## Non-goals

- Rival / mini-league modelling (deferred)
- Computer-use FPL execution (deferred)
- Vector retrieval / bulk unregistered scrape
- Re-enabling Sportradar
- Inventing odds, ratings or ranks when sources are absent

## Gap families (from weekly checkpoint)

1. Availability / role evidence
2. Transfers and signings
3. Set-piece roles
4. Promoted-team priors
5. World Cup return / fatigue
6. Timestamped licensed odds
7. Player ratings
8. Six-GW live-faithful forecast packet (hard approval blocker)

## Sequencing principle

Prefer slices that use **already registered / already captured** artifacts
before opening new rights. Agents may supply citations; collectors only run
where registry `enabled` and licence allow.
