# Source profile: football-data.org

- Registry: `football-data-org` (disabled).
- Use: independent basic fixtures, results and league-table reconciliation.
- Free tier: registered access, 12 competitions and 10 requests per minute at the
  time of review; verify again before enablement.
- Limits: not a replacement for historical odds, player events, FPL state or
  point-in-time news.
- Gate: approve registration, attribution, retention, rate-limit handling and a
  bounded comparison against canonical FPL fixtures.
