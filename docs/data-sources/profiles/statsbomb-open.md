# Source profile: StatsBomb open data

- Registry: `statsbomb-open` (disabled).
- Use: bounded method prototyping, not a default EPL production dependency.
- Content: selected competitions with matches, events, line-ups and some 360 data.
- Rights: follow the repository terms and attribute StatsBomb in derived research.
- Gate: verify competition/season fit, acquisition approval and an experimental
  question that cannot be answered with aggregate features first.

> **Status update — 28 July 2026:** The original disabled status above is
> superseded by source registry `0.6.0`. `statsbomb-open` is enabled only for
> deterministic transformation of already-acquired local files into a
> shadow-only ratings family, with required attribution. No downloader is
> enabled, EPL coverage is not assumed, and it remains outside the production
> dependency path. The registry entry is authoritative.
