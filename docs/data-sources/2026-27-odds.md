# 2026/27 odds source decision

Football-Data is the selected source for now. Its permitted role is deliberately
bounded: it supplies pre-closing historical match odds and a market comparator
for private analysis. Raw CSV files remain local, are attributed to
football-data.co.uk and are not redistributed through this repository.

The Football-Data note explicitly says ordinary odds columns are pre-closing;
columns with an additional `C`, such as `B365CH`, are closing odds. It also says
weekend odds are collected Friday afternoons and midweek odds Tuesday
afternoons. That is useful schedule evidence, but it does not give a
quote-level time or prove the exact public upload time.

## How it works

`src/ingestion/odds_snapshot.py` accepts already acquired CSV bytes. It prefers
complete Bet365 1X2 columns, then Pinnacle and then the Football-Data average.
It converts decimal odds to inverse probabilities and removes the bookmaker
margin by normalising the home, draw and away values to sum to one.

The output contains fixture identity, decimal odds, normalised probabilities,
the raw source hash and a derived content hash. It deliberately excludes final
scores and match results. Every row is labelled
`source_scheduled_preclosing` and initially
`live_forecast_admissible=false`.

For 2026/27, the source can become exact live evidence when our own immutable
capture observes the current pre-closing rows before an FPL cutoff.
`build_observed_live_snapshot` binds that observation time, availability time,
slot, payload and hashes. It refuses an observation at or after the cutoff.
Until such a capture exists, the corresponding slot remains unavailable. The
shared structured forecast continues without odds; no value is imputed.

## Relationship to the replay and live season

The supplied 2025/26 `E0.csv` is SHA-256
`3e3a8352f9ada6789c508d6ca184424421fed56a30400904a4a327c583407e62`.
It contains all 380 league matches, with complete Bet365 and average
pre-closing and closing 1X2 odds. Bet365's pre-closing and closing triplets
differ for 372 matches, showing that the pre-closing columns are a meaningful
earlier signal rather than aliases of the final prices.

For the enhanced 2025/26 replay, the pre-closing comparator can enter a
schedule-inferred exploratory arm. Friday/Tuesday collection is day-part
evidence, not an exact availability timestamp, so it cannot be silently merged
into the strict canonical replay. `FPL-bsw.38.12` must report this lower
temporal precision and abstain where the inferred collection window overlaps
the FPL decision cutoff. Closing `C` columns remain evaluation-only.

For 2026/27 live operation, official FPL state and the remaining structured
forecast continue normally. Scheduled immutable captures can attempt T-24h,
T-8h, T-2h and final. Because Football-Data is normally updated only on Tuesday
or Friday afternoon, some slots may contain unchanged quotes or no current
fixture row; staleness and absence must stay visible. A richer provider is
still required for native fixed-interval updates and player markets.

No network download, bookmaker account, browser action or FPL account write is
implemented by this adapter.
