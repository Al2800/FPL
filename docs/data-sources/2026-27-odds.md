# 2026/27 odds source decision

Football-Data is the selected source for now. Its permitted role is deliberately
bounded: it supplies historical match odds and a closing-or-unspecified market
comparator for private analysis. Raw CSV files remain local, are attributed to
football-data.co.uk and are not redistributed through this repository.

This selection does not turn a seasonal Football-Data CSV into a live odds
feed. The ordinary rows do not establish the instant at which each bookmaker
quote was available. Therefore they cannot fill the T-24h, T-8h, T-2h or final
pre-deadline slots and cannot enter the live forecast as
`registered_predeadline` evidence.

## How it works

`src/ingestion/odds_snapshot.py` accepts already acquired CSV bytes. It prefers
complete Bet365 1X2 columns, then Pinnacle and then the Football-Data average.
It converts decimal odds to inverse probabilities and removes the bookmaker
margin by normalising the home, draw and away values to sum to one.

The output contains fixture identity, decimal odds, normalised probabilities,
the raw source hash and a derived content hash. It deliberately excludes final
scores and match results. Every row is labelled
`closing_or_unspecified` and `live_forecast_admissible=false`.

The same module produces a checkpoint manifest. For Football-Data, all four
desired live slots are recorded as unavailable with
`source_has_no_quote_level_predeadline_timestamp`. The shared structured
forecast continues without odds; no value is imputed and no later observation
is backfilled into an earlier decision.

## Relationship to the replay and live season

For the enhanced 2025/26 replay, this comparator can measure whether the
engine's match-strength probabilities were aligned with the eventual closing
market. It must not be described as information available to the historical
agent unless separate quote-level temporal evidence exists.

For 2026/27 live operation, official FPL state and the remaining structured
forecast continue normally. Adding fixed-interval odds later requires a
separately registered provider, approved terms and cost, exact observation and
availability timestamps, immutable payload hashes and an isolated value
ablation. Football-Data remains useful even if that upgrade is never approved.

No network download, bookmaker account, browser action or FPL account write is
implemented by this adapter.
