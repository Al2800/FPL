# FPL-ecy: production line-ups and minutes integration

Build a provider-neutral capture/reconciliation path that the replay and the
live season both call.  First approve exactly one provider after a documented
EPL trial; then add its HTTP collector without changing the snapshot schema.
No provider failure can alter the shared structured baseline: it surfaces as a
degraded feature family.  Verify focused contract tests, then run one historic
fixture reconciliation and one live pre-season capture before activation.
